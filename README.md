# Supermarket Sales Analysis

## IBM SkillsBuild Data Analytics with AI Internship 2026

### Project Description
This project examines supermarket sales transactions to uncover useful insights about products, branches, categories, customers, payment methods, and customer ratings.

The project follows a complete, end-to-end data analytics workflow:
1. Load the dataset
2. Check and validate the data quality
3. Calculate and verify sales
4. Group and summarize the results
5. Build visualizations
6. Draw business insights
7. Suggest business decisions

## Dataset
**Dataset link:** [REPLACE THIS TEXT WITH THE ORIGINAL DATASET LINK]

The working dataset has **500 sales transactions** and 13 fields, including product, branch, city, customer type, gender, category, quantity, unit price, payment method, rating, and sales.

## Key Questions
- Which product earns the highest sales?
- Which branch performs the best?
- Which category sells the most?
- Which payment method is used the most?
- Do Members spend more than Normal customers?
- What is the average customer rating?

## Key Results
- Top-selling product: **Cheese — ₹27,906.30**
- Top-performing branch: **Branch C (Mumbai) — ₹72,469.45**
- Top-selling category: **Beverages — ₹56,108.24**
- Most-used payment method: **UPI — 127 transactions**
- Average Member transaction: **₹483.14**
- Average Normal transaction: **₹497.07**
- Average customer rating: **3.99 / 5**

## Setup and Run
1. Install Python 3.x on your system.
2. Install the required libraries with:

```bash
pip install -r requirements.txt
```

3. Keep the supermarket dataset in the same folder as the notebook.
4. Launch the notebook:

```bash
jupyter notebook SasetharThirumal_SupermarketSalesAnalysis.ipynb
```

5. Run all the cells from top to bottom.

If the default filename is not found, the notebook automatically searches for an Excel or CSV dataset.

## Business Decisions
The analysis supports the following:
- Keeping enough stock of fast-selling products and categories.
- Understanding what drives Branch C's strong performance.
- Continuing to support UPI payments.
- Improving customer service to raise ratings.
- Using customer spending patterns to plan membership offers.
